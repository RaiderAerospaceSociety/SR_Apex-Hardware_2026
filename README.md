# Hardware

This hardware project has four stackable PCBs—Power, Control, Sensor, and Telemetry—connected through pin headers.

## Folder structure

- `boards/` — Design files for the four PCBs.
- `shared/` — Hardware files used by multiple boards.
- `system/` — System-level design and documentation, including board connections.
- `manufacturing/` — Files for PCB fabrication and assembly.
- `tools/` — Hardware-related scripts and utilities.
